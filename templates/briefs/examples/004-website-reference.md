# Brief: 004-dashboard-redesign

## What

Redesign the dashboard — more data density, less whitespace.

## References

**Websites**

https://linear.app — love the compact layout and keyboard-first feel
https://vercel.com/dashboard — good balance of info density and clarity

**Text**

Current dashboard wastes too much space. Need to show:
- Project stats (count, active, overdue)
- Recent activity (last 10 items)
- Quick actions (new project, new task)

Everything above the fold on desktop. No scrolling to see the basics.

## Scope

Only the /dashboard page. Don't touch project detail or settings.
